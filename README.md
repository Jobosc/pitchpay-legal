# pitchpay-legal

Public legal pages for the PitchPay app, served with GitHub Pages
(Settings → Pages → Deploy from branch `main`, folder `/`).

| Page | Used for |
|---|---|
| `privacy.html` | Privacy policy URL (Google Play, App Store) |
| `delete-account.html` | Account deletion URL (Google Play → App content → Data deletion) |
| `index.html` | Landing page linking both |

Both pages are in English and German (`#de` anchor). Included as a git submodule in the
`pitchpay` app repository.
